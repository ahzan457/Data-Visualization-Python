# Data Visualization with Python

This repository contains my practical implementation for **Module 03: Data Visualization** as part of my Data Science Virtual Internship.

## 📌 Project Overview
This project focuses on building effective visual representations of data to uncover patterns, trends, and business insights using Python plotting libraries.

## 📊 Key Deliverables & Visualizations Built
- **Line Charts:** Tracked sales and expenses trends over time using Matplotlib.
- **Bar Charts:** Compared monthly performance metrics using Seaborn.
- **Histograms:** Analyzed the distribution frequency of numerical data.
- **Scatter Plots:** Explored correlations between sales and customer ratings categorized by product type.
- **Pie Charts:** Visualized categorical proportion breakdowns.

## 🛠️ Tools & Technologies Used
- **Python 3**
- **Matplotlib & Seaborn**
- **Pandas & NumPy**
- **Google Colab**
